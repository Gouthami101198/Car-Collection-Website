## 🌸 Visual Identity: Noir Black & Light Pink Atelier

The application features a bespoke **Black & Light Pink** aesthetic combining the stealth poise of deep obsidian noir with luminous, high-fashion light pink and rose metallic accents:

- **Jet Obsidian Noir (`#030304` / `#07070A`)**: Grounded in pitch carbon black surfaces, deep acrylic card backgrounds, and carbon-pattern overlays.
- **Radiant Light Pink (`#FFB6C1` / `#FF94B2` / `#FF6B93`)**: Used for metallic typography gradients, glowing badges, hover halos, tachometer needles, and call-to-action buttons.
- **Blossom Light Theme Mode**: One-click toggle in the navbar transitions into a chic cherry-blossom pearl palette with soft rose cards, crisp dark typography, and light pink borders.
- **Luxury Micro-Animations**: Glassmorphism blur layers, 3D card lift elevations, interactive hover sweeps, and live audio acoustic feedback.

### 5. On-Road Price Simulator & Bharat Series (BH) Tax Calculator
Located in the **Finance & RTO Advisory Section**, this tool models the exact on-road delivery price across India:
- **Comprehensive Component Breakdown**:
  $$\text{On-Road Price} = \text{Ex-Showroom} + \text{RTO Road Tax} + 1\% \text{ TCS} + \text{Insurance (3.8\%)} + \text{FASTag \& Registration}$$
- **Multi-State Tax Comparison**:
  - `Bharat Series (BH)`: Flat 8% (<₹10L), 10% (₹10L–₹20L), 12% (>₹20L) paid bi-annually with pan-India portability.
  - `Gujarat (GJ)`: 6.0% flat road tax for corporate and private collections.
  - `Delhi NCR (DL)`: 10.0% (Petrol) to 12.5% (Diesel) with 100% tax waiver on EVs.
  - `Rajasthan (RJ)`: 10.0% road tax.
  - `West Bengal (WB)`: 10.0% life tax.
  - `Maharashtra (MH)`: 13.0% road tax.
  - `Telangana (TS)`: 14.0% life tax.
  - `Tamil Nadu (TN)`: 15.0% one-time tax.
  - `Karnataka (KA)`: 18.0% lifetime road tax.
- **BH Tax Savings Counter**: Automatically displays net upfront tax savings compared to the highest state tax regime.

## ⚡ Getting Started

### Prerequisites
- **Node.js** (v18.0.0 or higher recommended)
- **npm** (v9.0.0 or higher)

### Installation & Local Development

1. **Clone or open the workspace**:
   ```bash
   cd "d:/Car Collection Website"
   ```

2. **Install dependencies** (if not already installed):
   ```bash
   npm install
   ```

3. **Start the local development server**:
   ```bash
   npm run dev
   ```
   Open **[http://localhost:3000](http://localhost:3000)** in your browser to view the application.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview the production bundle**:
   ```bash
   npm run preview
   ```
